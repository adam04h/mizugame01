V8.2 更新版
奇幻城堡冒險棋盤遊戲 V8.2

啟動方式：
1. 解壓縮整個 ZIP 資料夾。
2. 使用 Chrome 或 Edge 開啟 index.html。
3. 點擊開始遊戲、選擇角色，再於地圖頁按「開戰」。

V6.5 本次調整：
- 對決死亡：返回起始點、恢復角色原始 HP／攻擊／防禦與基本技能、金幣歸零、抽到的技能放回共用技能池。
- 致命毒刃：每個完整攻防回合對中毒對手造成 2 HP 傷害，直到死亡或對決結束。
- 每完成一輪雙方攻防，等待 3 秒後才進入下一輪。
- 對決三回合後，僅 1P 自身玩家可以選擇逃跑，不能控制 NPC 對手逃跑。
- 對決骰子移至左右角色肖像下方，左右對稱。
- 金幣獲得／損失視窗保留金幣圖案與並排卡片；窄螢幕只可水平滑動，不會向下排列滾動。
- 修正 11 種技能的數值與持續效果，並修正封脈禁咒為限制對手一個行動回合。

測試範圍：JavaScript 語法、HTML ID 唯一性、JS DOM 參照、素材路徑與功能條件靜態檢查均通過。此執行環境的 Chromium headless 無法正常結束程序，因此沒有將其標示為已完成瀏覽器互動測試；下載後仍建議在 Chrome 中實際進行對決流程測試。

注意：此版本仍是本機網頁原型；2P–4P 由 NPC 操控，尚未連接真人多人連線後端。

V7.6 商店格與冒險道具：
- 外圍第 3 格改為「商店」，不再發放金幣；踩到時開啟限時 15 秒的商店視窗，可提前離開。
- 紅色藥水：100 金幣，持有後可使用並恢復 5 HP。
- 疾風：1,000 金幣，持有後可使用以獲得 1 次拒絕對決機會。
- 隱身術：2,000 金幣，使用後自身角色淡化顯示 2 回合。
- 每種道具每次進入商店限購 1 個，單一道具最多持有 2 個；道具數量顯示在左側自身狀態欄的「冒險道具」區，可按「使用」。
- 商店使用紅金色奇幻道具卡片視窗，顯示金幣餘額、持有數量、購買限制及 15 秒倒數。

測試範圍：已執行 JavaScript 語法檢查、ZIP 完整性檢查及素材路徑／必要 DOM ID 靜態檢查。此環境中的 Chromium 測試頁面遭執行環境政策阻擋，未能完成互動式瀏覽器測試；建議在 Chrome 中實際確認商店倒數、購買與道具使用流程。

V7.9 多人遊戲大廳介面
- 流程：開始遊戲 → 多人遊戲大廳 → 選擇角色 → 遊戲地圖。
- 房主可建立房間、設定密碼及 NPC 數量；其他玩家進入時需輸入密碼。
- 等待加入的空位可由房主點擊切換為 NPC，NPC 位置也可切回等待真人。
- 目前是前端原型，房間狀態只存在當前瀏覽器，尚未連接多人伺服器；不同裝置間尚不能真正同步。
